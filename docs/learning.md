##硬性学习规则
1、总周期：连续7天学习计划；
2、【强制每日规则】：每一天学习开始，**必须安排15‑20分钟复习前一天全部核心知识点**；
3、学习角度分为：项目整体架构、目录结构、核心模块源码阅读、数据流转、存储设计(Redis短期记忆、memory‑bank md文件长期记忆)、Skill与AGENTS.md交互、多Agent调度、关键Python语法补全、面试可输出的项目亮点、面试话术提炼；
4、我是Java思维，讲解的时候尽量多做【Java类比】，把Python代码逻辑翻译成我熟悉的Java思路，降低理解门槛；
5、每一天输出结构固定：
①昨日复习任务（要复习哪些知识点，要思考哪几个问题）
②今日学习目标
③拆解今日学习模块（分模块，每个模块给出：看哪些源码文件、重点看什么、需要理解什么概念、需要做的实操）
④需要重点搞懂的关键问题（面试向，我需要能够口述回答）
⑤今日课后小作业（简单实操，读代码、画流程图、伪代码编写）
⑥今日总结要点（用于第二天复习）
