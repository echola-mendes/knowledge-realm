# 知域 — 产品需求文档

**产品名称**：知域  
**产品定位**：个人本机知识库 + AI 智能问答  
**界面形态**：Web  
**目标用户**：个人、本机使用为主  

---

## 1. 项目背景与目标

### 1.1 背景

个人积累的技术文档、电子书、博客、学习笔记、网页资料日益增多，传统文件夹和搜索方式难以快速找到、理解和利用已有知识。

### 1.2 目标

知域旨在将个人分散的文件、网页和笔记统一沉淀，并通过 AI 实现：

- 快速搜索知识
- 基于个人知识进行问答
- 自动总结和整理
- 知识关联与发现
- 多步骤研究和分析
- 智能管理个人知识

最终形成从 **“存储知识” → “搜索知识” → “理解知识” → “使用知识”** 逐步升级的个人知识助手。

---

## 2. 目标用户与核心场景

### 2.1 目标用户

以个人本机用户为主，数据按用户隔离。每个用户可拥有多个知识库。

### 2.2 核心场景

- **资料沉淀**：上传 PDF、Word、Markdown、TXT，或抓取公开网页，统一存入知识库。
- **知识搜索**：通过自然语言或关键词，快速检索个人知识。
- **AI 问答**：针对个人知识库提问，获得带来源引用的答案。
- **知识整理**：自动生成摘要、标签，提取实体与关系，发现关联。
- **研究分析**：让 AI 基于个人资料完成对比、总结、报告生成。
- **知识保鲜**：URL 文档可手动刷新，内容变更时保留版本记录并增量更新索引。

## 3. 已实现的需求

### 3.1 知识库与文档管理

#### 3.1.1 知识库管理

- 用户可创建多个知识库。
- 系统提供默认知识库；未指定知识库时，搜索与问答默认只使用默认库。
- 每个知识库独立管理、独立搜索。

#### 3.1.2 知识导入

支持以下导入方式：

- **文件导入**：PDF（文本层）、Word（.docx）、Markdown、TXT。
- **URL 导入**：输入公开网页地址，抓取正文并保存快照；抓取失败则导入失败。
- **手动创建**：用户可直接创建 Markdown 笔记。

#### 3.1.3 文档管理

- 文档列表、详情、阅读、删除。
- 文档重新处理。
- 文档收藏。
- 标签管理。
- 来源查看。

#### 3.1.4 文档处理状态

对用户可见的文档状态包括：

- **处理中**：待处理、解析中、待向量化、向量化中。
- **已完成**：可参与检索、问答与文档对比。
- **处理失败**：解析失败、向量化失败，失败原因可查看。

仅“已完成”的文档参与检索与问答。

---

### 3.2 知识检索

#### 3.2.1 向量语义搜索

- 基于语义相似度召回知识片段。
- 支持按知识库、标签、文档类型筛选。
- 搜索结果展示相关片段与来源文档。

#### 3.2.2 混合检索与重排序

- 支持向量检索与关键词检索的混合召回。
- 支持多路召回融合与重排序，提高相关性。
- 支持按时间、来源等维度筛选。

---

### 3.3 AI 问答

#### 3.3.1 RAG 问答

- 用户提问后，系统检索个人知识并生成答案。
- 答案附带知识来源引用，可追溯原文。
- 支持流式输出。

#### 3.3.2 多轮对话

- 支持连续多轮问答。
- 会话历史可用于理解上下文。

---

### 3.4 知识整理与增强

#### 3.4.1 智能摘要

- 对文档自动生成摘要。
- 摘要用于快速了解文档内容。

#### 3.4.2 自动标签

- 系统可为文档自动推荐标签。
- 用户也可手动添加、删除标签。

#### 3.4.3 实体与关系抽取

- 从文档中抽取实体与实体间关系。
- 实体与关系按知识库隔离。

#### 3.4.4 知识关联

- 基于实体、标签、向量相似度发现相关文档。
- 用户可查看“这篇知识和哪些内容有关”。

#### 3.4.5 文档对比

- 用户可选定多篇文档，由 AI 对比分析异同。

---

### 3.5 Agent 与研究报告

#### 3.5.1 Agent 任务

- 用户可发布复杂任务，例如：“总结知识库中关于 RAG 的资料，并对比不同优化方案。”
- Agent 可自主规划、检索、调用工具、整理信息并生成报告。

#### 3.5.2 工具调用

- Agent 可调用搜索工具、网页搜索工具等。
- 工具调用结果作为回答依据，并记录引用。

#### 3.5.3 会话记忆

- Agent 会话支持短期记忆、会话摘要与长期记忆。
- 记忆按用户隔离。

#### 3.5.4 研究报告

- Agent 可生成结构化研究报告。
- 报告包含引用来源，便于用户核对。

---

### 3.6 收藏、标签与推荐

#### 3.6.1 收藏

- 用户可收藏文档或知识片段。
- 提供收藏内容统一入口。

#### 3.6.2 标签

- 支持手动标签与自动推荐标签。
- 可通过标签筛选文档与搜索结果。

#### 3.6.3 主动推荐

- 首页根据用户收藏与最近问答命中的资料，推荐相关文档。
- 推荐结果去重，并排除已收藏本体。

---

### 3.7 可观测与调试

#### 3.7.1 调试页

- 提供检索调试页，展示检索过程与中间结果。
- 展示 Agent 执行轨迹与推理步骤。

#### 3.7.2 回答质量评估

- 支持对 RAG 回答进行质量评估。
- 评估维度包括忠实度、相关性、完整性等。

#### 3.7.3 Token 与耗时

- 调试页展示 LLM 调用的 Token 用量与 Pipeline 各阶段耗时。

---

### 3.8 版本与更新

#### 3.8.1 版本管理

- 文档内容变更时，版本号递增并记录版本元数据。
- 相同内容不重复生成版本。

#### 3.8.2 增量更新

- 内容变更重新索引时，仅对变化部分重新生成索引。
- 未变更部分复用已有索引。

#### 3.8.3 URL 文档刷新

- 用户可手动刷新 URL 文档。
- 内容未变更提示“已是最新”；内容变更则版本递增并增量更新索引。
- 支持批量刷新知识库内全部 URL 文档。

---

### 3.9 知识洞察

#### 3.9.1 知识冲突检测

- 针对知识库内文档，检测是否存在对同一事实的表述矛盾。
- 只生成报告，不自动修改数据。

#### 3.9.2 知识缺口分析

- 基于知识库内容与检索低命中记录，分析可能缺失的知识主题。
- 输出报告供用户参考。

#### 3.9.3 自动知识整理

- 自动为无标签文档补打标签。
- 输出整理报告，提示疑似重复、空摘要、命名不规范等问题。

---

## 4. 规划中的需求

### 4.1 知识图谱可视化

- 基于已抽取的实体与关系，提供力导向图谱可视化页面。
- 支持按知识库查看图谱、搜索高亮实体、点击节点查看关联文档。
- 为 Agent 增加基于图谱的检索能力，支持按实体关系多跳召回相关文档。

### 4.2 个人出行 Agent

- 在现有 Agent 对话内增加出行意图分支。
- 支持机票、酒店搜索比价与多套方案对比。
- 支持按用户口头偏好定制方案。
- 支持用户确认后下单，落本人预订记录，并展示支付链接（供应商提供时）。
- 支持查询与取消本人预订。

### 4.3 高级知识智能化

- 多 Agent 协作。
- 更复杂的知识冲突检测与知识缺口分析。
- 自动知识整理与主动知识推荐增强。
- 知识库自动更新与定时轮询。
- 知识去重增强与元数据管理。

### 4.4 可观测与评估增强

- Agent 执行效果评估。
- RAG 检索与回答质量的系统级评估。
- 执行 Trace 与日志。
- Token、延迟等监控指标。

---

## 5. 非功能需求

### 5.1 易用性

用户应能无门槛完成：

> **上传资料 → 等待处理 → 直接提问**

无需理解复杂的 AI 概念。

### 5.2 可追溯

AI 回答尽可能提供知识来源，方便用户核对。

### 5.3 数据私有

个人知识数据以本地存储为主；AI 服务仅发送完成任务所需的最少数据。

### 5.4 身份与安全

- 用户身份只来自 Session，禁止通过请求参数指定用户身份。
- 不做 RBAC、OAuth、JWT。
- 数据按用户隔离。

### 5.5 可扩展

后续可扩展更多知识来源、AI 模型、Agent 能力、搜索能力、多人协作与团队知识库。

---

## 6. 版本说明

- **V1.0 / P0**：基础知识库，支持文档导入、向量检索、RAG 问答、标签、收藏、Web 界面。
- **P1.1–P1.4**：智能摘要、自动标签、知识图谱数据落库、文档对比、知识关联、Agent、研究报告。
- **P2**：检索增强（混合检索、重排序、关键词与时间/来源筛选）、Agent 记忆与工具路由、网页搜索。
- **P3 第一批**：知识洞察（冲突检测、缺口分析、自动整理）、版本与增量更新、URL 刷新、主动推荐、Token 与回答质量可观测。
- **P3 第二批（规划中）**：知识图谱可视化、`search_graph` 图谱检索。
- **P4（待批准）**：个人出行 Agent。
