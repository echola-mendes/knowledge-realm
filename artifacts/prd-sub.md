# 子需求：工具菜单 + 我的行程单（A→B）

## 需求理解

主侧栏保持知识库为主；新增「工具」入口。工具页内二级菜单「旅程」展开后进入「我的行程单」。先做导航壳（A），再做行程落库与列表（B）。

## 功能范围

- A：侧栏「工具」→ `/tools`；页内二级导航「旅程」→「我的行程单」；空态 + 去对话规划入口
- B：`plan_record` 落库（save 时写入）；`GET /api/plans` 本人列表；前端真实渲染；可打开方案页（有 url 时）

## 非目标

- 不在全局侧栏做多级展开
- 本期不做 AI 资讯 / AI 生图页面（仅预留工具 IA）
- 不新建独立 Chat；规划仍走 Multi Agent

## 验收标准

- A：侧栏可见「工具」；进入后可展开旅程并看到「我的行程单」空态
- B：规划生成方案后列表出现记录；跨用户不可见；无 MinIO 时仍可有记录（html 可无 url）
